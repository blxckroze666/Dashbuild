How To Put It Live Free

1
Go to github.com and create a free account if you don't have one.
2
Click New Repository. Name it anything (e.g. my-dashboard). Set it to Public. Click Create.
3
Click Add file → Upload files. Upload your downloaded dashboard HTML file. Rename it index.html before uploading.
4
Go to Settings → Pages. Under Source select Deploy from a branch. Pick main branch. Click Save.
5
Wait 2 minutes. Your dashboard is live at: yourusername.github.io/my-dashboard — free forever.
